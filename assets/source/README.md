# Источники визуалов января

- `ravshann-snow-cutout-original.png` — предоставленная вырезанная фотография для вступления. Оптимизированная версия: `public/assets/visuals/ravshann-snow-cutout.webp`.
- `ravshann-face-beard-original.png` и `ravshann-face-clean-original.png` — предоставленные портреты для смены лица по прокрутке. Оптимизированные версии находятся в `public/assets/visuals/`.
- `public/assets/visuals/winter-abstract.svg` — нарисованный в коде единый абстрактный фон января.
- `brothers-square-original.png` — предоставленный квадратный постер для сцены «Брат и Брат 2». Оптимизированная версия: `public/assets/visuals/brothers-square.webp`; края смягчаются средствами CSS без обрезки файла.
- `public/assets/visuals/mafia-duology.png` — предоставленный прозрачный арт с RavshanN и встроенной цитатой для сцены Mafia 1 / Mafia 2; в проекте хранится исходный PNG без обрезки.
- `public/assets/visuals/litvin-sedation.png` — предоставленный прозрачный арт для сцены выпуска Литвина; исходный PNG без обрезки, края смягчаются средствами CSS. Видео подключено по ссылке YouTube, файл не хранится в проекте.
- `input.mp4` и `Ravsh 2.mp4` предоставлены отдельно и остаются у заказчика. Для сайта подготовлены облегчённые копии `public/assets/video/brat-1.mp4` и `brat-2.mp4` (720×720, 30 кадров/с, звук сохранён), а также кадры обложек. Титры и водяные знаки исходных роликов сохранены.

Постановочные изображения не являются архивными кадрами новогоднего стрима.
