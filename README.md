# RavshanN / SLAY KING 2026

Локальный прототип сайта-хроники: **главная страница + январь**. Это не официальный ресурс премии и не система голосования. Дизайн января — рабочая концепция, не утверждённый финал.

## Запуск

```bash
pnpm install
pnpm dev
```

Откройте адрес, который напечатает Vite. Проверки:

```bash
pnpm typecheck
pnpm test
pnpm build
```

## Что сделано

- Hero с предоставленным вырезанным портретом RavshanN, CTA «ПРОЙТИ ГОД» и переходом к январю.
- Золотая линия прокрутки, устойчивые якоря сцен, навигация вперёд и назад.
- Три январские сцены в форматах 16:9, 9:16 и split. Их названия взяты из исходного реестра и остаются **непроверенными редакционными пунктами**.
- `PLACEHOLDER` вместо отсутствующих фото и видео. Компонент медиа поддерживает YouTube по клику, без автозвука, со ссылкой на оригинал.
- Режим показа: `←`/`→` для точек, `PgUp`/`PgDn` для пролога/января, `Esc` для выхода. Клавиши работают только во включённом режиме.
- Адаптивная верстка, семантические заголовки, видимый фокус и reduced motion.

## Контент и структура

Исходный реестр 46 черновых пунктов хранится в `src/content/events.2026.json` без изменения. Для публичного прототипа отображаются только три пункта января из `src/content/january.scenes.json`. Их ID и исходные названия валидируются при запуске. Февраль и другие месяцы здесь не оформлены.

Январские точки расширения: `src/chapters/january/designBrief.ts`, `chapter.motion.ts`, `chapter.module.css`, `assetManifest.ts`. Общие компоненты и навигация не привязаны к искусственному шаблону всех 12 месяцев.

## Необходимые материалы

| Ассет | Статус | Что требуется |
| --- | --- | --- |
| Hero-портрет | Получен от заказчика, утверждение применения ожидается | Подтвердить права на использование и финальную ретушь |
| Фон января | MISSING | Утвердить арт-направление, затем сделать декоративные кропы 16:9 и 9:16 |
| Новогодняя ночь | MISSING | Оригинальное видео или фото, источник, права, короткая подпись |
| «Брат и Брат 2» | MISSING | Оригинальный вертикальный материал или фото, источник, права |
| «Мафия 2+1» | MISSING | Оригинальная запись или кадр, источник, права |
| Голосование и соцсети | MISSING | Официальные URL после проверки; пока CTA голосования нет |

Промпт для **декоративного фона** хранится в `assetManifest.ts`. Он не предназначен для создания поддельных кадров событий.
