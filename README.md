# RavshanN / SLAY KING 2026

Локальный прототип сайта-хроники: **главная страница + январь + два события февраля**. Это не официальный ресурс премии и не система голосования. Дизайн глав — рабочая концепция.

## Запуск

```bash
pnpm install
pnpm dev
```

Откройте адрес, который напечатает Vite. Проверки:

```bash
pnpm typecheck
pnpm test
pnpm build
```

## Что сделано

- Hero с предоставленным вырезанным портретом RavshanN, CTA «ПРОЙТИ ГОД» и переходом к январю.
- Золотая линия прокрутки, устойчивые якоря сцен, навигация вперёд и назад.
- У заголовка января — предоставленный вырезанный кадр RavshanN в снегу, встроенный прямо в зимний фон без рамки.
- Весь январь расположен на едином абстрактном зимнем полотне: векторные ледяные линии, снежная пыль, холодные блики и редкие золотые акценты. Фотофон не повторяется по секциям.
- После зимней сцены расположен видеоблок новогоднего стрима. Рядом — два предоставленных портрета: пока секция и её фон закреплены, прокрутка раскрывает лицо без бороды справа налево. Пока запись стрима не готова, на её месте явно обозначенный зимний `PLACEHOLDER`.
- В сцене «Брат и Брат 2» слева размещён предоставленный квадратный постер с мягкими краями, справа — увеличенный телефон. Два видео запускаются по кнопке и переключаются стрелками; у каждого ролика есть своя ссылка «Архив записи стрима» в Telegram. В сцене новогоднего стрима такая ссылка ведёт на его архив. Оптимизированные MP4 и обложки лежат в `public/assets/video/`.
- Следующая сцена посвящена Mafia 1 и Mafia 2: предоставленный прозрачный арт встроен слева в общее зимнее полотно, шесть ссылок на записи сгруппированы по игре, под ними оставлен видеоблок 16:9 без выдуманного ролика.
- Четвёртая сцена — выпуск Литвина «Кто последний уснёт?»: предоставленное фото справа плавно растворяется в общем фоне, слева находится встроенное видео YouTube 16:9, которое загружается по нажатию.
- Перед запуском видео Литвина показывается обложка самого выпуска с YouTube.
- После января идёт февраль на непрерывном зимнем фоне. Первое событие — встреча с Хамзатом Чимаевым: предоставленное фото слева и три вертикальных ролика в стиле ленты рилсов справа. Ролики переключаются стрелками, точками или свайпом; загружается только выбранное видео.
- Второе событие февраля — закреплённая при прокрутке сцена «Дерби в Казахстане → 15 суток»: афиша с четырьмя участниками сменяется юмористической реконструкцией с RENATKO и ANAR. Переход обратим при прокрутке вверх; есть кнопка пропуска и статичный вариант для reduced motion. Реального видео пока нет, ссылка не выдумана.
- Четыре январские сцены. Исходные названия сохранены в реестре, экранные заголовки — редакционные; сами события остаются **непроверенными пунктами**.
- `PLACEHOLDER` вместо оставшихся отсутствующих медиа. Компонент медиа поддерживает YouTube по клику, без автозвука, со ссылкой на оригинал.
- Режим показа: `←`/`→` для точек, `PgUp`/`PgDn` для перехода между прологом, январём и февралем, `Esc` для выхода. Клавиши работают только во включённом режиме.
- Адаптивная верстка, семантические заголовки, видимый фокус и reduced motion.

## Контент и структура

Исходный реестр 46 черновых пунктов хранится в `src/content/events.2026.json` без изменения. Для прототипа отображаются четыре пункта января и первые два пункта февраля из `src/content/january.scenes.json`, `src/content/february.scenes.json` и `src/chapters/february/derbyContent.ts`. Их ID и исходные названия сверяются с реестром при запуске. Остальные события февраля и другие месяцы здесь не оформлены.

Январские точки расширения: `src/chapters/january/designBrief.ts`, `chapter.motion.ts`, `chapter.module.css`, `assetManifest.ts`. Общие компоненты и навигация не привязаны к искусственному шаблону всех 12 месяцев.
